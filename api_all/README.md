# API_ALL

Every API station, script and spec for the Faith Through Physics pipelines, gathered in one place for the ONE_MENU build.

- Start with `00_READ_ME_FIRST.md` (where every folder came from).
- **The build task is `CODEX_MASTER_PROMPT.md`** (supersedes `CODEX_PROMPT_ONE_MENU.md`, which stays as detail).
- `09_SOURCE_API_FOLDERS/`: code and prompts from `pipeline-workflows/API` (run data left out).
- New station specs: `08_NEW_STATION_SPECS/` (Story V2, Master-equation analog V2, Analytical Arms V1, Statistics Wall V1 + matrix prototype).

No API keys are stored here. Keys come from environment variables such as `DEEPSEEK_API_KEY`.
