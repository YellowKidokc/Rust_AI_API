# Open AI CALL

Use this folder for academic, high-rigor writing passes.

## Suggested flow

1. Drop source material into `inbox/`.
2. Reuse prompts from `prompts/`.
3. Store academic templates in `templates/`.
4. Write polished markdown into `markdown/`.
5. Keep scripts in `scripts/`.
6. Use `work/` for temporary files.
7. Send finished output to `outbox/academic/`.
