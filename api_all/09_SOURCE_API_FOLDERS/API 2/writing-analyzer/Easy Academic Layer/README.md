# Easy Academic Layer

This folder is the contained call layer for batch writing work.

## Layout

- `Deep Seek Call/` for easier rewrites and draft-level passes.
- `Open AI CALL/` for academic, higher-rigor passes.
- `outbox/easy/` for Deep Seek outputs.
- `outbox/academic/` for OpenAI outputs.

## Rules

- Keep inputs in `inbox/`.
- Keep reusable prompt files in `prompts/`.
- Keep reusable source templates in `templates/`.
- Keep working markdown in `markdown/`.
- Keep script helpers in `scripts/`.
- Keep scratch work in `work/`.
- Put finished markdown or export artifacts in the appropriate outbox.
