# Deep Seek Call

Use this folder for easier, lower-complexity writing passes.

## Suggested flow

1. Drop source material into `inbox/`.
2. Reuse prompts from `prompts/`.
3. Store any reusable template text in `templates/`.
4. Write draft markdown into `markdown/`.
5. Keep scripts in `scripts/`.
6. Use `work/` for temporary files.
7. Send finished output to `outbox/easy/`.
