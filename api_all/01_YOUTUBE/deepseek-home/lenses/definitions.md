# LENS: key terms

Find the terms the argument depends on (faith, evidence, miracle, information, design, etc.) and how the speaker defines or uses them. `why`: the working definition, and flag equivocation where a word shifts meaning mid-argument. `use`: whether it matches or conflicts with David's GLOSSARY.
