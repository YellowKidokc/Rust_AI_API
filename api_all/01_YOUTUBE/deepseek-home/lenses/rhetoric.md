# LENS: delivery and persuasion

Ignore whether the claims are true. Look at *how* the speaker persuades:
- analogies and illustrations that make an abstract point concrete
- reframes: the moment the question is recast so the answer changes
- reversals: turning an objection back on the objector
- sequencing: how a point is set up before it is delivered
- tone shifts: humor, gravity, a personal disclosure used to earn trust

Start `label` with the move in brackets, e.g. `[analogy] ...`. In `use`,
say how David could reuse the technique (not the content) in his own writing
or teaching. Flag manipulative moves (loaded framing, straw men) as such.
