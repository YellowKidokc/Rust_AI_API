# LENS: scripture use

Find every Bible passage quoted, cited or clearly alluded to. `label`: the reference (book chapter:verse, or 'allusion: ...'). `why`: how the speaker uses it (proof text, illustration, context-read, reinterpretation) and whether the use fits the passage's context. `use`: whether David can rely on this reading.
