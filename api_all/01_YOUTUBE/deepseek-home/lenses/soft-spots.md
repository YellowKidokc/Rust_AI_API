# LENS: soft spots

Find where the reasoning in this video is weakest, on every side:
- **concessions**: a speaker grants a point to the other side (even in passing)
- **hedges**: "I think", "maybe", "some scholars say" carrying a load-bearing step
- **overclaims**: a conclusion stated more strongly than the evidence given supports it
- **dodges**: an objection raised and not actually answered
- **gaps**: a step the argument needs that nobody states or defends

Start `label` with the kind in brackets, e.g. `[concession] ...`.
In `why`, name the argument affected. In `use`, say how David would shore up
his own version of that argument, or how he would press the point against
the other side. Be even-handed: David's own side gets no pass.
