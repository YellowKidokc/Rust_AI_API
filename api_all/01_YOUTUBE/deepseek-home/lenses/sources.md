# LENS: sources named

Find every book, paper, scholar, scientist or authority named or quoted. `label`: author + work. `why`: what the speaker uses it for, and whether it is represented fairly as far as the transcript shows. `use`: whether David should read it and why. Never invent a title the speaker did not give.
